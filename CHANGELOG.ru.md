# История изменений

[English](CHANGELOG.md) · [Русский](CHANGELOG.ru.md) · [简体中文](CHANGELOG.zh-CN.md)

## 1.0.1

- Добавлен перенос строки в терминале через `Shift+Enter` без отправки текущего промпта.
- Исправлены выбор терминала и клавиатурный фокус: ввод сразу идёт в xterm выбранной живой карточки, а нажатие по пустому канвасу снимает выбор и рамку.
- Добавлен опциональный автофокус при наведении с задержками входа и выхода: медленно (`500ms`), обычно (`250ms`) и быстро (`80ms`). Программный hover focus больше не отправляет focus-report sequences в TUI агента и не перебрасывает его в начало истории.
- Добавлены независимые настройки направления колеса для терминала и канваса. По умолчанию колесо вниз прокручивает терминал вниз, а зум канваса сохраняет прежнее направление.
- Вывод PTY объединяется в renderer-обновления по 16 мс, а повторное копирование строки scrollback заменено ограниченным chunk-буфером. Это устраняет мигание при больших объёмах вывода и сокращает сбросы истории.
- Очереди записи настроек, реестра плагинов и разрешений медиакаталогов теперь восстанавливаются после временных ошибок файловой системы, а метаданные клиентов провайдеров соответствуют версии приложения в пакете.
- Добавлено полное руководство по runtime-плагинам на упрощённом китайском, синхронизированы инструкции по терминалу на трёх языках и описаны локальные данные плагинов, медиапапок и браузера.
- Добавлена лицензия MIT и локализованы Security, Changelog, Architecture и UI Contract.

## 1.0.0

- Добавлена лёгкая локальная стартовая страница, которая появляется до инициализации настроек, плагинов, медиа и IPC; ошибки bootstrap теперь показываются на видимой странице с fallback на нативный диалог вместо пустого окна.
- Добавлена блокировка второго экземпляра Electron: повторный запуск восстанавливает и фокусирует существующее окно.
- Координаты указателя терминала преобразуются из CSS-трансформации канваса обратно в координаты layout xterm, поэтому выделение текста, mouse reporting в vim/tmux и прокрутка работают при любом масштабе.
- Переработаны сочетания буфера обмена терминала: копирование через `Ctrl+C` при выделении, `Ctrl+Shift+C` или `Cmd+C`; вставка через `Ctrl+Shift+V`, `Cmd+V` или `Shift+Insert` с использованием `Terminal.paste`. Сочетания привязаны к физическим клавишам и работают с нелатинскими раскладками.
- Добавлен smoke harness упакованного приложения (`CANVASTTY_SMOKE_TEST=1` печатает `CANVASTTY_SMOKE_READY` после первого кадра) и подключён к Linux release pipeline под `xvfb-run` с FUSE2.

## 0.9.99 — публичное превью

- Добавлен permissioned registry runtime-плагинов для готовых статических GitHub-репозиториев.
- Добавлены manifest v1 contributions: sandboxed HOME widgets, перемещаемые canvas apps и отдельные окна CanvasTTY.
- Добавлены preview и проверка permissions перед установкой, включение/выключение/uninstall, изолированное storage, CSP-ограниченные assets и общий host SDK.
- Добавлены постоянные разрешения на выбранные пользователем музыкальные каталоги, seekable локальные аудиопотоки и ограниченные API чтения/записи плейлистов.
- Добавлена sandboxed core-заготовка встроенного браузера с вкладками, навигацией, постоянным изолированным профилем и геометрией карточки; из HOME она намеренно не запускается.
- Фиксированная композиция HOME заменена на просторную сохраняемую сетку `16 × 12` с визуальным редактором перемещения и размера при сохранении утверждённой раскладки.
- Добавлены resize окон и HOME widgets за любую грань, видимые только при редактировании границы HOME, временное размещение за границей, проверка перед Save и изоляция edit mode от остальных окон канваса.
- Добавлена документация архитектуры/runtime-плагинов и полный пример пакета Studio Kit.

## 0.9.2 — публичное превью

- Поиск CLI провайдеров сделан кроссплатформенным: пользовательские каталоги CLI разрешаются в Linux и Windows, поэтому AppImage и Windows-сборки находят установленные `codex`, `claude` и `kimi`.

## 0.9.1 — публичное превью

- Восстановлен поиск CLI провайдеров при графическом запуске AppImage: desktop `PATH` дополняется существующими пользовательскими каталогами, включая `~/.kimi-code/bin`.
- Поздние terminal input/resize events больше не роняют main-процесс Electron при гонке с завершением PTY (`EBADFD`).

## 0.9.0 — публичное превью

- Исправлено непоявление главного окна, когда renderer успевал отрисоваться до завершения `loadURL`; listener `ready-to-show` теперь устанавливается заранее.
- Добавлено RTS-движение канваса от краёв, выключенное по умолчанию и останавливающееся над интерактивными поверхностями.
- В Settings добавлены переключатель/скорость движения от краёв и чувствительность зума колесом.
- Settings разделены на General, Appearance и Controls.
- Добавлены режимы Off, Single click и Double click для фокуса/приближения терминала; автоматический click focus выключен по умолчанию.
- Добавлены переназначаемые application shortcuts: `Home` для домашней зоны и `F2` для inline-переименования окна, а также скрываемая живая подсказка.
- Состояние PTY и scrollback сохраняются при смене палитры, узора, настроек и собственного заголовка окна.
- Улучшены clipboard shortcuts терминала, resize за края, semantic zoom и многоязычная документация.

## 0.8.2 — публичное превью

- Release jobs публикуют только пользовательские установщики без распакованных каталогов сборки.
- Windows NSIS и portable executables получили разные имена артефактов.

## 0.8.1 — публичное превью

- Проверки безопасности репозитория и документации работают в checkout с LF/CRLF и Windows drive paths.
- Поведение приложения не изменилось относительно preview candidate `0.8.0`.

## 0.8.0 — публичное превью

- Пространственный канвас для живых локальных PTY и CLI-сессий AI-агентов.
- Фиксированная Home-зона с launcher, sessions, clock, media и лимитами провайдеров из реальных источников.
- Перемещаемые и изменяемые по размеру terminal cards с snapping и semantic zoom navigation.
- Изоляция процессов Electron с типизированным IPC из белого списка и локальными настройками.
- Точки входа и документация на английском, русском и упрощённом китайском.
- Воспроизводимая упаковка Linux, Windows и macOS через GitHub Actions.
- Аудит секретов репозитория и строгий allowlist содержимого пакета.

Ограничения превью: runtime widget plugins ещё не реализованы; Windows и macOS требуют более широкой проверки на реальных устройствах; release packages не подписаны и не notarized.
