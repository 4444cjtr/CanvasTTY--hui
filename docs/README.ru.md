## Текущая модель расширения

Пользовательский виджет в CanvasTTY — это изменение на уровне исходного кода, компилируемое вместе с приложением, а не сторонний runtime-плагин. Для MVP это сознательное ограничение: возможности Electron ограничены белым списком, общие данные типизированы, а учётные данные провайдеров никогда не попадают в renderer.

Если появится runtime API плагинов, эту документацию нужно будет переработать вокруг явной модели разрешений, а не считать текущие примеры из исходников стабильным публичным ABI.

## Жёсткое правило для данных

Нельзя выдумывать статус сессии, счётчики, квоту, расход токенов, стоимость, таймеры обратного отсчёта или прогресс. Используйте реальный структурированный источник, а если он не может ответить — показывайте `loading`, `stale`, `unavailable` или `error`.
