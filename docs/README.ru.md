## Текущая модель расширения

CanvasTTY пока не загружает сторонние runtime-плагины. Пользовательский виджет — это вклад на уровне исходного кода, который компилируется вместе с приложением. Для MVP это сознательное ограничение: возможности Electron остаются в белом списке, межпроцессные данные — типизированными, а credentials провайдеров никогда не попадают в renderer.

Если появится runtime API плагинов, документацию потребуется пересобрать вокруг явной модели разрешений. Текущие примеры исходников нельзя заранее считать стабильным публичным ABI.

## Неподвижное правило данных

Нельзя выдумывать статус сессии, счётчики, квоту, токены, стоимость, таймеры или прогресс. Используйте настоящий структурированный источник, а если он не отвечает — показывайте `loading`, `stale`, `unavailable` или `error`.
