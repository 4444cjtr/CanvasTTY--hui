# Документация CanvasTTY

[English](README.md) · [Русский](README.ru.md) · [简体中文](README.zh-CN.md)

## Текущая модель расширения

CanvasTTY поддерживает статические runtime-плагины через manifest API v1. Недоверенный UI остаётся внутри sandboxed iframe/окон и получает только явно подтверждённые capabilities. Доверенные core-интеграции, которым нужен новый main-process service, по-прежнему добавляются на уровне исходников и компилируются вместе с приложением.

## Жёсткое правило для данных

Нельзя выдумывать статус сессии, счётчики, квоту, расход токенов, стоимость, таймеры обратного отсчёта или прогресс. Используйте реальный структурированный источник, а если он не может ответить — показывайте `loading`, `stale`, `unavailable` или `error`.
